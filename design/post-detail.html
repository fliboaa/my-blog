引言

Flexbox 是一种极其强大的布局模式。当我们真正理解它的工作原理后，就能构建出会自动响应、按需重排的动态布局。

比如，看看下面这个：Adam Argyle 的 codepen用了 零 个 media query 或 container query。它用流体原理创造了一个无缝流动的布局。

💡 提示

本文假设你已经了解 flexbox 基础。如果你是新手，建议先读我之前的 Flexbox 入门。

为什么需要弹性布局

相关的 CSS 其实很简单：

form {
  display: flex;
  align-items: flex-end;
  flex-wrap: wrap;
  gap: 16px;
}

/* 每个输入项会按需伸缩 */
.name {
  flex-grow: 1;
  flex-basis: 160px;
}

当容器变窄时，.name 字段会收缩到它的 flex-basis；再窄下去，整个表单会换行，而不是溢出。这一切都是自动的。

flex-grow 的秘密

flex-grow 决定了可用空间如何分配。默认值 0 意味着"不索取额外空间"。设成 1，元素就会瓜分剩余空间。

想象一张桌子，每个人先放下自己的餐盘（flex-basis），然后桌上还剩位置，flex-grow 决定谁能伸手去占。
⚠️ 注意

flex-grow 不是比例！它是"瓜分剩余空间的权重"。两个都设 grow:1 是平分，但 grow:2 和 grow:1 不代表 2/3 和 1/3——还要看 basis。

实战演示

下面是一个完整的可运行示例。试试拖拽分隔线，观察元素如何自适应：

  • flex-grow: 1 — 瓜分所有剩余空间
  • flex-shrink: 1 — 允许收缩
  • flex-basis: 160px — 起始基准宽度

常见陷阱

很多人第一次用 flexbox 会踩这几个坑：

  1. 把 flex-grow 当成宽度比例
  2. 忘记 min-width 会导致无法收缩
  3. 混淆 align-items 和 justify-content 的轴向

总结

Flexbox 的精髓不在记住多少属性，而在理解"可用空间如何分配"这个底层模型。一旦想通了这点，所有属性都会变得自然。
